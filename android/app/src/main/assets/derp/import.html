Import data

Bring your bookmarks and passwords from another browser. Export them there as a file, get the file onto this device (email it to yourself, or use a cloud drive), then choose it here.

Bookmarks

  • Chrome on a computer: Bookmark manager → ⋮ → Export bookmarks
  • Edge: Favorites → ⋯ → Export favorites
  • Derp or Firefox on a computer: Bookmarks → Manage bookmarks → Import and Backup → Export Bookmarks to HTML
  • Safari on a Mac: File → Export → Bookmarks

Passwords

  • Chrome: Password Manager → Settings → Export passwords
  • Edge: Settings → Passwords → ⋯ → Export passwords
  • Derp or Firefox on a computer: Passwords → ⋯ → Export passwords
  • Safari on a Mac: File → Export → Passwords

The exported file isn’t encrypted, so delete it once it’s imported. In Derp, your passwords are encrypted and stay on this device.
